# OtyaHQ — Otya Ecosystem

Otya is a connected technology ecosystem building practical products for media, business operations, identity and private productivity.

## Products and platform

- **Omy Play** — a local-first media application for music, video, private media and device-to-device transfer.
- **Opoint** — Otya's internal business operations platform for retail, inventory, workforce and agency workflows. It is designed for Otya's own company operations, not as a public multi-tenant SaaS.
- **Otya ID (OID)** — shared account identity with verified-email sign-in and authenticator-based security.
- **O** — a private owner application with owner-specific tools and AI capabilities.
- **OEnd** — shared web, backend and integration services.
- **OHub** — public developer and partner documentation.

## Public information

OHub is the public source for developer guidance, product boundaries, safe API examples and partner information. Use official product websites and documentation for current releases and support details.

## Security

Please report potential security vulnerabilities through the process in the OHub security policy. Do not publish credentials, private user data or exploit details in public issues.

Otya publishes product capabilities only when they are supported by current release and verification evidence.
